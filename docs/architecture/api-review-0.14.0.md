## How to read this

`cargo-public-api` reports one line per *path*, so an item reachable at three
paths is three lines and a module demotion looks like a mass removal. The raw
line diff across this cycle is **-144**, and it is uninformative. Three
collapses turn it into a review, each applied to **both** releases so neither is
privileged, and each reported separately so a category is never silently
absorbed into another:

1. **`pub mod` lines are namespace, not item** ([D-208](s13-decision-register.md#d-208)).
2. **Paths collapse to identities.** `macrame::a::b::Name` and
   `macrame::prelude::Name` are the same item; the *count* of paths is held
   aside, because reducing it is exactly what D-208 did and is not an API
   change.
3. **`#[non_exhaustive]` is stripped into a flag**, because
   [D-207](s13-decision-register.md#d-207) added it to ten types deliberately
   and it renders inline on the item's own line.

What survives all three is a genuine addition or a genuine removal, and that is
the list at the bottom -- the one the acceptance item asked to be read.
