## §11 Milestones

| Phase | Deliverable | Exit gate |
|---|---|---|
| M1 — Schema + integrity | DDL, migrations, triggers, audit_current, rebuild_current | Drift-audit property test passes on random streams |
| M2 — Temporal core | as_of, reconstruct, snapshots, cold-DB fold, AttributeMode | Monday/Wednesday/Friday scenario; reconstruct(now) == live property; cold-DB roundtrip |
| M3 — Graph + vectors | CTE builder, DiskANN search, hybrid RRF, native `Subgraph` ([D-039](s13-decision-register.md#d-039) — this said "petgraph bridge" until 0.5.4) | Golden-string CTE tests; dimension-rejection tests |
| M4 — Write Actor | Actor loop, priority channels, chunking, containment | Priority-interleaving concurrency test; prefix-visibility test |
| M5 — Archive + hardening | Archive session, cold storage, fuzz suite, benchmark gates | All [§9](s6-s10-flows-to-dependencies.md#9-performance-budgets) budgets met; archive roundtrip verified |

**Status against these gates (0.5.4).** M1, M2 and M4 are delivered. M3 is delivered except hybrid RRF, which is one pure fusion function with no FTS5 table behind it ([§5.9](s5-modules.md#59-vector--embeddings-the-model-registry-and-search)). M5 is partial: the archive session and cold storage exist and are property-tested, the fuzz suite is the generated-history suites of [§8](s6-s10-flows-to-dependencies.md#8-testing-strategy), and the benchmark gates do not exist — so "All [§9](s6-s10-flows-to-dependencies.md#9-performance-budgets) budgets met" is an exit gate nothing currently measures.

The first code written is the drift-audit property test, the Monday/Wednesday/Friday attribute-fidelity test, and the priority-interleaving concurrency test, because together they pin the three invariants every later change must preserve: that belief is honest, that fidelity is declared, and that the user is never made to wait for a background job.

| <a id="r15"></a>R15 | libSQL access violation when local databases are opened concurrently in one process (0.5.4) | Low in production, High in test | Low, after mitigation | Found while building the property suite: an intermittent STATUS_ACCESS_VIOLATION (0xc0000005), reproduced with no Macrame types in the loop — open, migrate, drop, repeat. Below the [Doctrine I](s0-s3-foundations.md#doctrine-i) line, so carried as a risk rather than fixed. **Not fixed upstream:** the dependency was moved 0.6.0 → 0.9.30, the latest stable release, three minor versions on; the crate compiled unchanged and the fault rate did not move. **The first diagnosis was wrong and is corrected here.** It was recorded as scaling with the sheer number of databases, on a volume sweep (0/8 at ~64 and ~128, 1/8 at ~384) that in hindsight varied concurrency alongside volume. The dominant factor is concurrency: one binary in isolation faulted 2/40 with libtest's default thread pool and 0/40 with `--test-threads=1`, and the full suite went from 1/20 to 0/30 on that change alone. Volume is at most secondary. The old reading also mispredicted the blast radius — the fault is not confined to the property harness; replay_snapshot, write_path and temporal binaries have each died mid-run. Mitigated in two places, both self-documenting: `RUST_TEST_THREADS = "1"` in .cargo/config.toml (which `[env]` does not force, so the fault stays reproducible on demand), and the `property-tests` feature gate over the two generated-history binaries, which are the residue that serialising does not fix — doctrine_property_tests still faults ~3/25 because a property case needs a database of its own. Plain `cargo test` measures 0/30. Not masked by the gate: proptest replays every previously found failure from .proptest-regressions before generating a new case, so defects already caught stay caught, and the gated binaries run as their own step. Production exposure is nil by construction — an application opens one Database and holds it for its lifetime — and remains the load-bearing claim: if this is ever observed with a single long-lived Database, this row is wrong and the risk is severe. To be reported upstream against 0.9.30 with the raw reproduction. |
